# Nerocopia

## Introduction

Nerocopia is a recipe management application built with Laravel and a React frontend using [Inertia](https://inertiajs.com).

Inertia allows the app to be a modern, single-page React application using classic server-side routing and controllers, combining the frontend power of React with the backend productivity of Laravel and lightning-fast Vite compilation.

The frontend utilizes React 19, TypeScript, Tailwind, and the [shadcn/ui](https://ui.shadcn.com) and [radix-ui](https://www.radix-ui.com) component libraries.
